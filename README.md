# Motion Ski

A motion-controlled skiing game for the BeagleY-AI (ENSC 351, Fall 2026). Players lean, jump and crouch with a chest-mounted IMU to steer down a three-lane slope on HDMI, with a breadboard joystick, lane LEDs and a buzzer for menus and feedback.

Team: Sehajvir Dhillon, Alfonse Teruel, Hassaan Nasim, Enoch Liu.

Build: `cmake -S . -B build && cmake --build build`. Full instructions coming with the main loop.
